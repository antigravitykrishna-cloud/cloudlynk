# Archive

These documents are from earlier phases of the project (some predate the
Streamly → Cloudlynk rebrand, some predate the premium-content-access
pivot). They're kept for history but are **not accurate for the current
build** — branding, package names, pricing model, and in some cases the
entire monetization flow described in them have since changed.

Do not use these as a reference for the current app. See the top-level
`README.md`, `BUILD.md`, `BACKEND_REFERENCE.md`, and `CHANGELOG.md`
instead.

`TEST_PLAN.md` in particular describes a 30-minute free-usage paywall with
Basic/Standard/Premium dollar pricing tiers — that flow no longer exists.
Premium is now: flat 15GB storage for everyone, and premium unlocks
access to specially-flagged content. A new test plan reflecting the
current app should be written before the next real testing pass.
